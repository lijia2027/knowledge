# 案例索引与验收重点

每个案例可按任务口径、数据与可用时间、基线、滚动回测、预测服务、业务验收和复盘记录。

## 风电场功率预测系统

参考[风电功率预测](../applications/wind-power)。验收覆盖 NWP 起报时间、限电和停机口径，按提前量及爬坡时段记录误差。

## 光伏电站预测系统

参考[光伏功率预测](../applications/solar-power)。验收覆盖辐照度、云量与白天有效时段，记录快速变化天气下的预测误差。

## 园区负荷预测系统

参考[电力负荷预测](../applications/load)。验收覆盖工作日与节假日、极端温度、高峰负荷及其发生时刻。

## 日前电价预测系统

参考[电力市场与价格预测](../applications/electricity-market)。验收覆盖提交截止时间、尖峰价格，以及误差对交易决策的影响。

## 风光储联合预测与调度系统

参考[区域新能源出力预测](../applications/regional-renewables)和[预测与优化调度](../applications/dispatch)。验收覆盖预测误差、约束可行性及调度收益。

## 储能电池健康管理系统

参考[电池 SOH](../applications/battery-soh)、[电池 SOL](../applications/battery-sol)和[电池 RUL](../applications/battery-rul)。验收覆盖未见电芯、不同老化阶段、终止条件和预测区间。
